Use the links below to open the notebooks in Google Colab. Each link opens the
current notebook on `main`. Run the installation cell before the other cells;
it installs the published `mmcfilters` package and the notebook dependencies.

Examples read images from a local clone when available. If an example image is
missing, the notebook downloads it from the `v7.0.0` repository snapshot.
