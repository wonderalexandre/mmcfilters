# Changelog

All notable user-facing changes are recorded here. This project follows
Semantic Versioning for release tags; research snapshots between tags may carry
post-release versions generated by `setuptools-scm`.

## Unreleased — next major version

### Changed

- `ExtinctionValues::computeFormalSaliencyEdgeMap` and the Python method with the
  same name now implement the Cousty persistence hierarchical watershed through
  an altitude-ordered MST/BPTAO and full-graph QFZ projection. This is a
  same-name semantic breaking change.
- The former max-descendant extinction valuation followed by direct LCA
  projection is available explicitly as
  `computeMonotoneExtinctionProjection`.
- Formal hierarchy projection distinguishes edge saliency values from positive
  partition-appearance levels through `HierarchyLevelConvention`.
- Canonical ranked maps now rank values realized on graph edges, avoiding gaps
  introduced by unused node levels or the dominant-extremum sentinel.
- Notebook documentation is maintained in English and imports installed
  packages directly with `import mmcfilters`.

### Removed

- Ambiguous raster `saliencyMap` entry points. Use `contourMap` for a pixel
  visualization and the edge-indexed hierarchy APIs for formal saliency maps.
- Integer overloads whose meaning mixed top-k selection with thresholds. Use
  `ExtinctionSelectionPolicy`.
- Notebook-only local extension loaders and installation cells.

### Added

- `HierarchicalWatershedSaliency`, `ShapeSpaceSaliency`, explicit monotone
  extinction projection, hierarchy-level conventions, and canonical edge ranks.
- A canonical saliency guide, scientific implementation references, and
  automated notebook policy checks.

See [docs/saliency.md](docs/saliency.md) for the scientific contracts and
implementation provenance.
